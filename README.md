# RowIQ — Erg Performance Visualizer

Three dashboard prototypes for visualizing rowing erg performance data, plus a
password-gated showcase wrapper for sharing them.

## What's here

- `erg-dashboard` — baseline performance dashboard prototype
- `v2-athlete-cards` — athlete-card-based layout iteration
- `v3-timeline-explorer` — timeline-based exploration view
- `rowIQ_women_dashboard` — a dashboard variant for a women's program
- `erg-showcase` — the password-gated wrapper used to share the prototypes

Built with Vite + TypeScript.

## Status

Prototype stage — these are design/UX explorations of how to present erg data, not a
production training platform.
